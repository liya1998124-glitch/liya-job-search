# Liya Qiuzhi · 李雅求职

把一份简历变成可执行的求职计划。适用于应届生、在职求职者、转行者和管理岗候选人。城市、薪资、行业、资历和工作制度由你设定。

## 安装与使用

下载本仓库，把整个 `liya-qiuzhi` 子目录放进 Codex 项目的 `.agents/skills/`，或放进个人目录 `~/.agents/skills/`。打开新会话，输入 `$liya-qiuzhi`。也可以在支持 Agent Skills 的其他客户端按其目录约定导入。

只给简历即可开始整理经历和推导求职方向。给岗位链接、JD 或截图可直接做适配分析。实时搜岗和公司核验需要宿主具有可用的搜索和页面读取工具，部分信息受当地公开范围及平台访问限制。建议提供去掉联系方式、住址和证件号码的简历。

## 可以这样用

- “这是我的简历。给我三个值得找的方向，说明每个方向的优势和差距。”
- “帮我找五个符合条件的岗位，给原链接、三个评分和投递优先级。通勤和固定薪资是硬条件。”
- “核实这家公司和实际签约主体，看看公开渠道有没有劳动争议、欠薪或经营异常线索。”
- “按这个 JD 改简历，给我一条沟通话术和五道可能被追问的面试题。”
- “这个岗位我已投递，三天后收到了一面邀请。帮我更新台账并做模拟面试。”

匹配度、岗位数据可信度和公司可信度分别展示。每个评分附依据、缺失项和下一步。投递和联系招聘方由用户决定。
